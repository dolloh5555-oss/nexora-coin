# NEX ฟรี — Render Free Web Service

ชุดนี้เป็นหน้าสาธารณะ ไม่ใช้ SQLite ไม่มีบัญชีผู้ดูแล ไม่ต้องใช้ NEX_SETUP_TOKEN และไม่ผูกดิสก์
หน้าแรก / และ /market เป็นตลาด; /swap เลือกคู่เหรียญและเปิด PancakeSwap; /buy จำลองการซื้อและอ่านยอดสาธารณะบน BSC
ยังไม่ส่งธุรกรรมหรือรับเงินจริง ไม่มีระบบฟาร์มหรือฝากเงิน

## อัปโหลดให้ตรงกับ GitHub ของคุณ
1. แตก ZIP แล้วเปิดโฟลเดอร์ nexora-render
2. บน GitHub เปิด repository nexora-coin แล้วเข้าโฟลเดอร์ nexora-render ที่มีอยู่
3. Add file > Upload files แล้วลากไฟล์และโฟลเดอร์ทั้งหมดที่อยู่ข้างใน nexora-render จาก ZIP นี้ไปวาง ห้ามลากโฟลเดอร์ nexora-render ครอบซ้ำ และห้ามอัปโหลด ZIP
4. Commit changes ตรวจ nexora-render/render.yaml มี plan: free และไม่มี disk หรือ NEX_DATA_DIR
5. Render > New > Blueprint เลือก repository เดิม; Name: nexora-free; Branch: main; Blueprint Path: nexora-render/render.yaml
6. หน้าสรุปต้องเป็น Free ไม่มีดิสก์หรือฐานข้อมูลเสียเงิน จึงค่อยกดยืนยันสร้างบริการ
7. รอ Live แล้วเปิด URL ที่ Render ให้ได้เลย ไม่มีขั้นตอนตั้งผู้ดูแล

หากสร้างบริการเสียเงินไว้แล้ว: ชุดนี้ใช้ชื่อบริการใหม่ ไม่ได้ยกเลิกบริการหรือดิสก์เดิมให้ อาจมีค่าใช้จ่ายเดิมต่อ ต้องตรวจ Billing และบริการเดิมก่อน รวมถึงเก็บข้อมูลเดิมก่อนลบทรัพยากร
หากมี Blueprint เดิมที่เผยแพร่สำเร็จและ sync อัตโนมัติแล้ว ให้ตรวจสถานะนั้นก่อนอัปโหลดทับ เพราะการแก้ YAML อาจสร้างบริการใหม่
ไฟล์ index.html, app.js หรือ tests เก่าที่ค้างใน GitHub จะไม่ถูกเปิดให้เข้าจากเว็บนี้ server ใหม่อนุญาตเฉพาะรายการไฟล์สาธารณะ

## ข้อจำกัด Free
บริการพักเมื่อไม่มีคนเข้า 15 นาที การเปิดครั้งแรกหลังพักอาจรอประมาณหนึ่งนาที
มีโควตารวมรายเดือน ไม่ใช่บริการฟรีไม่จำกัด ตั้ง spend limit ตามบัญชีและตรวจ Billing หากมีวิธีชำระเงินผูกอยู่
ไม่มีข้อมูลบัญชีหรือรายการคลังที่ต้องรักษาในดิสก์ จึงไม่ต้องเสี่ยงฐานข้อมูลหายตอนพัก
ภาพพื้นหลังต้นฉบับใหญ่ประมาณ 19 MB ระบบให้เบราว์เซอร์แคชรูปหนึ่งวัน แต่ผู้เข้าชมครั้งแรกยังใช้แบนด์วิดท์มาก
เว็บผู้ดูแลเดิมในเครื่องไม่ได้ถูกแก้ไขหรือถูกลบ
